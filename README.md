# 聊天记录年轮（ChatTreeRings）

> **100% 本机离线个人数字年轮与互动动力学测绘仪**  
> 一套安全、充满仪式感的本地聊天记录分析仪器。

---

## 它是什么

通过解析本地导出的聊天记录（支持标准 TXT 两行块格式、单行方括号格式、CSV 表格及 JSON 数组），将其绘制成生动的年度回忆年轮：

- **7×24 小时生物钟热力矩阵**：统计周一至周日各时段消息密度，测算深夜活跃比（22:00–04:00）；
- **破冰者（Icebreaker）判定**：当相邻消息间隔超过 6 小时后首位发言者被记为一次主动破冰，量化双方破冰比例；
- **回复延迟与秒回率**：在同一会话窗口内（交替发言且 $\le 2\text{ 小时}$），计算回复耗时中位数与 60 秒内秒回占比；
- **月度年轮环与连续天数**：按月份可视化双方消息量增长轨迹，统计全年最长连续聊天天数与最长断联天数；
- **年度高频实义词**：过滤纯虚字停用词，提取年度最具代表性的交流短语。

---

## 它不是什么

- **它不是云端统计服务**：100% 本机纯离线运行，绝不发起任何网络请求或遥测；
- **它不是社交监控软件**：纯本地数据结构与时间戳统计，不存储或转发任何明文聊天内容。
